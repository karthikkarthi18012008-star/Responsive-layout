# ✈️ TravelEase – Responsive Hotel Booking Page

A responsive hotel booking webpage built using **HTML5 and CSS3**, demonstrating the practical use of **Flexbox, CSS Grid, Media Queries, Forms, and Responsive Tables**.

The webpage is designed to provide a clean booking experience across **desktop, tablet, and mobile devices**.

---

## 📌 Project Overview

**TravelEase** is a responsive hotel booking interface where users can:

- View the TravelEase navigation menu
- Enter their personal booking details
- Select a destination
- Select check-in and check-out dates
- Enter the number of guests
- View a booking summary
- View available hotel rooms and their pricing
- Access the webpage comfortably on desktop, tablet, and mobile devices

The main purpose of this project is to demonstrate how **Flexbox and CSS Grid can be combined with responsive design techniques** to create a mobile-friendly webpage.

---

## 🎯 Objectives

This project was developed to practice:

- HTML5 semantic structure
- CSS Flexbox
- CSS Grid
- Responsive web design
- CSS Media Queries
- HTML forms and input elements
- Responsive tables
- Mobile-first layout adjustments
- Clean and structured webpage design
